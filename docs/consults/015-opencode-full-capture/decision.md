# Decision015
Extend only observed native read/write/edit/bash, preserving matched call/session/tool/argument identities. Use existing action_executed artifact/hash/version contract, not nonexistent memory_write. Before write capture intended content digest and verify post-file hash. Edits must reconstruct expected output safely or explicitly label the result a post-operation observation; do not claim exact authored provenance. Revalidate project paths/nearest existing parent before and after, deny credential paths, symlink escapes and oversize/ambiguous captures. File mutations use conservative unknown/high classification unless existing policy positively classifies them; do not assume all config/workflow changes reversible/low. Bash always unknown/high with digest-only command summary. Missing/nonzero exit never produces success evidence; may emit explicitly failed attempt only if existing contract supports truthful status, otherwise latch/deny subsequent actions. Never transmit commands, output, diffs, diagnostics or bodies. Capture failures latch session. Existing read semantics unchanged. No automatic retries without durable receipt protocol. Acceptance includes installed revoked-source denial, actual write/edit hashes, zero secret/body transmission and before/after/path/metadata mismatch failures. Cross-session/restart durability remains separately evaluated. Domain/security dissent overrides initial low-risk proposal.
