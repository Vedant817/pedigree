Choose **A: validate raw shape/allowed keys, normalize aliases, validate canonical models**, once for the complete batch before authorization, quota admission or writes. Reuse constrained field types with direct REST/MCP inputs; avoid importing FastAPI into the engine.

Preserve source/source_read/source.create and source-kind-only forms; memory/memory_created/remember; action/action_executed/tool_use/tool_executed; session/session_start/ensure_session; session_read/read (`adapters.py:29-74`). Preserve source_kind, tool_name, title-as-action-summary and memories-as-relied_on aliases, rejecting conflicting simultaneous values instead of choosing silently. Hooks actually emit source_read/source_kind plus session_read (`pedigree_hook.py:90-120`; `pedigree-core.js:516-518`); E3 uses ensure_session/source_kind (`evals/run_e3.py:34-49`). Preserve recognized aliases, optional nulls where existing producers emit them, session inheritance and generic fallback for unknown runtime names. Reject unknown operations/extras: migrate the explicit old silent-ignore test (`test_events.py:82-88`) and document this intentional tightening. Do not discard forbidden trust assertions before P-015 checks.

Use strict strings, booleans and integers; actual lists of strict items, never string iteration, scalar wrapping or truthy defaults. Enforce enums, ID regex and shared LIMITS (`config.py:31-69`): text2000, summary300, URI512/title160, dependencies64/corroborators16, conf8 with items32, artifacts16 with items512, IDs128; artifact_key1024 matches current engine. Validate hash syntax, required session/node IDs, item bounds and extras before mutation. Reject C0/DEL in identifiers, URI and artifact strings without trimming/rewriting identity. For prose allow LF/tab explicitly, reject other C0/DEL; preserve accepted bytes. Engine validators remain defense in depth.

REST validation failures should return 422 invalid_argument with fixed message and bounded field-location/code entries only; omit Pydantic input, ctx and echoed unknown field names. Preserve established 413 batch/body limits. Unexpected REST errors return fixed internal plus a server-generated UUID. Never trust incoming correlation text as a diagnostic identifier. Typed errors need a safe detail allowlist too: current validate_id echoes input (`config.py:165-168`).

Wrap each entire MCP tool, including _resolve, not only its engine lambda (`mcp_server.py:114-123`); sanitize SDK validation errors separately, covering direct calls and transports. Diagnostics may log operation, safe exception-class identifier and UUID, never str(exc), raw params, exc_info or bearer values (`app.py:32-35`; `mcp_server.py:31-32`).

Replace Content-Length-only middleware (`app.py:38-49`) with pure ASGI bounded actual-byte collection/replay before downstream dispatch, including /mcp. Reject on overflow immediately without forwarding partial bodies or unbounded draining. Configure standalone SDK limits using its observed contract. Test chunked, false-length, malformed batches, injected auth/registry faults and secret-bearing exceptions.

Confidence: high; compatibility fixtures and real transport tests remain mandatory. No implementation/runtime proof claimed.
