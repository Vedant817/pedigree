# Security consult

Release blockers, from source inspection; no runtime security PASS claimed:

1. **Tenant database credentials are not enforced.** `db/client.py:145-146` uses shared settings; REST authentication sets graph/identity (`api/auth.py:37-47`), and MCP passes shared Db to engines (`mcp_server.py:262-286`). Scope a tenant Db after live bearer resolution, retain a separate registry/admin Db, and reject graphs outside exact tenant/main, what-if and checkpoint namespaces. Derive distinct tenant passwords from a deployment secret. Include scoped quota mutex keys and SET/GET/EVAL commands: quota admission uses these (`engine/quota.py:37-38,89-109`). Existing ACL test omits coordination access and checkpoints (`tests/security/test_acl_mechanism.py:25-30,53-54`). Acceptance: service-created ACL clients execute normal writes, quotas, revoke, what-if and checkpoint; REST/MCP isolate tenants; direct cross-tenant reads/copies, registry reads, GRAPH.LIST and foreign mutex writes fail. Fail closed on provisioning failure; never fall back to admin. Verify restart reprovisioning after Redis loses ACL state.

2. **Hook outages lose evidence and allow ungated actions.** Artifact lookup precedes event creation (`adapters/claude/pedigree_hook.py:404-413`); a network exception exits through warning/zero (`:525-528`). Build immutable capture envelopes locally, persist before delivery, use stable event IDs, serialize replay, and bind spool ownership to endpoint plus credential identity without storing credentials. Bound disk use; report full/corrupt storage explicitly. Do not replay stale gate decisions as authorization. Acceptance: kill server before Read, restart hook/server, verify exact source/session edges persist once; interrupt after server commit/before acknowledgement, replay without duplication; verify credential rotation/account switching cannot replay across tenants. Installed runtime capture remains separate evidence.

3. **Default launch seeds production.** Compose sets production plus seed (`docker-compose.yml:21-22`); runtime invokes seeding (`scripts/runtime.py:171`). Production must start empty, require a strong admin credential, reject demo-login/seed flags, and preserve existing volumes. Acceptance: fresh authenticated production boot has zero tenants/nodes; restart preserves a real API-written sentinel.

4. **Recovery needs an offline boundary.** Checkpoint names exist (`config.py:166-170`) without restore implementation. Do not present GRAPH.COPY as atomic live restore. Require stopped writers, checkpoint verification, pre-restore backup, recoverable staged replacement, and failure injection around each destructive step. Nonexpiring quota mutexes require quiescence (`engine/quota.py:1-6`). Preserve the crashed old volume untouched.
