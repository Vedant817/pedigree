# P-002 — README checker

Status: landed 2026-10-18. The 20-second GIF is not in the repo.

`scripts/check_readme.py` fails when `README.md` is missing one of the required
headings, links a `docs/*.md` file that is not in the tree, or states a
measurement that `scripts/check_numbers.py` would reject. Headings inside a
code fence do not count. `make check` runs it after the numbers check.

The first screen names the CI workflow file and says a hosted run is not
claimed. The three E1 figures above the fold are the same recall,
over-invalidation, and preservation-status values already in the evaluation
table. Compose commands stay the ones in the quick start. No-Docker remains
`make quickstart` and `make quickstart-windows`.

The architecture and data-model sections include Mermaid diagrams. The Cypher
section quotes `Q_REVOKE_ROOT`, `Q_QUARANTINE_CHUNK`, and `Q_TAINT_PARENT`.
Blame is the `taint_parent` chain plus a bounded hop path, not Cypher
`shortestPath`. `Agent` stays a reserved label with no shipped writer.
