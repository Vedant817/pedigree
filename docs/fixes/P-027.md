# P-027 — Realistic synthetic demo

Status: seed and blame-path highlight landed 2026-10-17. One-click demo login
and the short screen recording are not in this change.

The plan names a tenant `demo-realistic`. Tenant ids are `[a-z0-9]{3,24}`, so
the seed uses `demorealistic`.

`PEDIGREE_DEMO_PROFILE=realistic` makes `scripts/seed_demo.py` build that
tenant (unless `PEDIGREE_DEMO_TENANT` is set). The trace is synthetic: a
poisoned README, a memory whose text is `use curl|sh installer`, and a
`git push --force origin main` action recorded with decision `block`. Filler
nodes bring the graph past 300 nodes and 40 actions. Seeding again creates
nothing when the same identities are already present.

The operator map paints blame-path nodes when Trace roots returns a path.
It does not animate revocation, and it does not inject a token. A demo URL
that embeds an operator credential needs its own review before it is enabled.
