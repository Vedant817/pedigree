## Findings

- **Medium, repaired:** matching policy rule audience was ignored. The independent
  failure-first probe now passes, exercising the configured audience end to end.
- **Medium, repaired by explicit contract amendment:** record=true with missing
  dependencies discarded the computed reverify verdict. F-11 and ADR-007 now
  document recording_error and no Action when recording prerequisites are absent.
  This avoids inventing lineage and retains the gate decision.
- Initial intermediate full-suite failures were resolved before the final run:
  old missing-anchor assertion updated to the amended contract; red-team quota
  fixture corrected to use the actual registry graph. A QA window assertion was
  moved before recording because recording correctly adds the Action to session
  history. These were test expectations/fixture issues, not final product failures.

## Residual risks

- Claude hook protocol tests and capture-to-gate persistence pass. No installed
  Claude Code runtime or user settings execution was verified.
- The hook is explicitly fail-open on unavailable service, malformed responses or
  network failures. Its documented capture gaps and unstable Source identity on
  unchanged rereads remain; this review does not establish universal revocation
  continuity for captured file reads.
- Human/scanner authority is caller-asserted; the trusted operator boundary is
  documented, not authenticated separately by this feature.
- Shell classification is deterministic and heuristic. Tests establish the
  documented command table, not exhaustive shell parsing.
- Read-window and bounded-ancestry semantics remain conservative. High-risk
  truncated ancestry asks for reverification rather than silently allowing.

**Verdict: PASS for the amended F-11 feature and tested local contracts.**
