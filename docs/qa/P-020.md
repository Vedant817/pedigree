The test module proves these independent adversarial groups:

1. Real FalkorDB 42201 indexed hit/miss with 257 additional synthetic rows in an
   isolated registry graph. Every well-formed supplied hit/miss performs one exact
   live digest query. EXPLAIN contains `Node By Index Scan` and no `Label Scan`.
   Agent/operator roles, nullable legacy slots and cross-row ambiguous digest
   rejection are verified. This is query-plan/count evidence, not a production
   latency or mathematical constant-time claim.
2. Another Python process rotates the operator credential and then revokes the
   tenant. The already-used parent registry immediately rejects the old authority
   without calling invalidation. Child/parent output contains booleans only;
   credentials are passed privately on stdin, never command-line text.
3. Deterministic injected-clock reservations test destructive/read/write atomicity.
   A rejected destructive reservation does not spend the opposite budget.
4. Twelve-thread contention admits exactly three writes for each of two tenants;
   forty additional active keys are denied at capacity. Exhausted keys retain their
   denial, bucket/deque bounds hold, and exact window expiry frees expired state.
5. Actual TCP REST and mounted installed-SDK MCP share one service limiter across
   agent/operator credentials. Exactly two combined writes succeed, the third REST
   request returns 429 with `Retry-After: 60`, and only two physical nodes exist.
   A distinct combined read budget also admits exactly two reads.
6. Actual TCP allows ten unauthorized REST failures, ignores changing caller
   `Forwarded`/`X-Forwarded-For`, then blocks valid MCP and REST credentials from
   the same peer. The MCP retry is bounded to 60 seconds. Injected clock expiry
   permits both protocols again, proving the selected shared-IP denial tradeoff.
7. Actual TCP REST unrecorded gate spends read budget while installed-SDK recorded
   MCP gate spends write budget. Subsequent what-if is write-rate rejected.
8. Actual TCP real and dry-run revoke both share the destructive bucket with MCP
   reinstate. Each opposite reservation is denied without spending its ordinary
   read/write bucket, checked by consuming its full remaining capacity.
9. A real subprocess launched through shipped `pedigree.cli mcp --transport stdio`
   accepts ten invalid-token failures with varying claimed tenant IDs, then denies
   the configured valid default. This is actual stdio server-local backoff evidence;
   stdio expiry is not timed by that subprocess test.
