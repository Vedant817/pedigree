## Findings and fixes during the round

- **Fixed (HIGH):** hash-less Source identity raced under concurrency - 8 identical writers of
  the same uri produced 7 nodes, because a MERGE keyed on a NULL `content_hash` is not protected
  by the `(uri, content_hash)` unique constraint (NULLs are exempt; measured with 10 concurrent
  writers producing 50 nodes). Fix: hash-less captures derive a stable id from
  `sha256(tenant|uri)` and MERGE on the `Node(id)` constraint.
- **Fixed (MEDIUM):** the hashed path now reads the node back on a conflict instead of surfacing
  an error to the caller.
- **Fixed (MEDIUM):** `Db` held one FalkorDB connection for all threads - 160 concurrent writers
  turned load into `unavailable` timeouts. Connections are now per-thread.

## Residual, stated not softened

- A single-host deployment that pastes the operator token into an agent's environment still has
  one principal; the rule binds the agent *channel*, not the machine (KNOWN_ISSUES 18).
- Per-tenant DB ACL users are verified but not wired into the service (KNOWN_ISSUES 18).

**Verdict: PASS.**
