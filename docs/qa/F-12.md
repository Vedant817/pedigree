## Notes and one fixture-level rule

- `demo/scenarios/S6.json` declares `expected_gate` (the docs/03 section 5 `gate:{step:verdict}`
  shape) and no `expected_after_revoke`, so the replay does not revoke it: a gate scenario must be
  evaluated with its lineage intact. `evals/run_e3.py` now revokes a root only when the fixture
  declares what the revoke should produce.
- `src/pedigree/demo.py` `_preflight_existing` compared `conf` against a hard-coded empty list, so
  a fixture that *declares* a confidentiality tag collided with itself on re-seed. Fixed to compare
  the fixture's declared value (covered by `test_seed_is_repeatable_without_touching_unrelated_data`
  and the CLI credential test).

## Residual, stated not softened

- Confidentiality is declared by the *caller* (`audience`) and inherited at write time; there is no
  declassification flow (per docs/01 §6.5, a declassify is a new Memory with an explicit human
  source - which the operator-credential corroboration path provides).
- The S6 pattern is a replay of the published confused-deputy/label-flow idea, not the paper's
  experiment.
