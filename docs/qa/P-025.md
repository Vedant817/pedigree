## Residual risks
- Dockerfile entrypoint/CMD only runs `pedigree.cli serve` (`bash scripts/entrypoint.sh`) so the
  factory contract is implicit - documented but not mechanically checked. If a future deploy
  switches to `uvicorn pedigree.api.app:app`, it will fail at import; recommend CI greps for the
  factory string.
- The "lifespan runs a startup scan over all registry tenants" pattern from P-011/P-024 calls
  `graph_name()` first; tenant rows written before the tensure regex overhaul (e.g. invalid legacy
  ids from early experiments) are logged as skipped participants. Combined with
  validate_id/validate_tenant input tightening, new ones cannot be created via /admin/.
- Module-level settings/build if invoked directly (`pedigree.mcp_server.build_mcp`) still needs a
  settings/DB argument - documented in the spec.

Verdict: **PASS**.
