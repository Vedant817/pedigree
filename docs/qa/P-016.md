## Residual risks / not verified by me

- True POSIX `SIGTERM` shutdown was not testable on Windows; `CTRL_BREAK_EVENT` performed the full
  uvicorn graceful path incl. session-manager teardown (section 5), which is the observable proxy.
- The acceptance phrase "all three pass on a clean clone" was not reproduced against a fresh
  clone + fresh venv by me; my runs are against the frozen commit with an empty `git status`
  (`src/`/`tests/` byte-identical across the two later spec-only commits).
- HTTP transport-level auth (`Authorization` header) is not consumed by the mount; per spec that is
  P-015 scope and the `opencode.json` header is currently inert for auth. Recorded, not tested
  beyond the tool-token contract.
- The stdio no-token default-tenant path (P016-QA-2) deserves the red-team pass; I verified the
  behaviour and its HTTP non-exposure, not the full threat model.
- Graph totals drift while other agents work in the same DB; per-run deltas were measured to be
  exactly zero (section 7), a whole-DB absolute check was not stable by construction.
