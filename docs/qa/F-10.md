## Findings

- **High, repaired:** unconditionally replaying fixture corroboration replaced
  existing `by=agent` with `by=human`. The same revoked preserved memory's gate
  changed from block to allow after reseeding. The dedicated support query now
  sets authority only when creating a new edge; independent repro remains block.
- **Medium, repaired:** the old implementation skipped any existing fixture id,
  then attached synthetic human support to a colliding user memory. Whole-fixture
  identity/content/lineage preflight now rejects collisions before node or edge
  creation. Matching mutable lifecycle state remains intact for repeat seeding.

## Residual risks

- Scenario dependencies and attestations are authored synthetic fixtures. No
  actual edit, commit, push or external web request is executed or proven here.
- Seeding is sequential, without a cross-operation transaction or concurrent
  seeder guarantee. Missing support may be repaired for matching fixture nodes;
  existing support authority is preserved.
- `scratch/` ignore and nonprinting are verified. Windows credential-file ACL
  isolation beyond normal local filesystem permissions was not established.
- The scans cover tracked files/history; the CLI test independently checks its
  ignored generated credential path and output. No credentials are published.
- Combined UI/browser acceptance and the final repository `make check` belong
  to the root integration run, not this scoped F-10 verdict.

**Verdict: PASS for F-10 scoped acceptance after the two verified repairs.**
